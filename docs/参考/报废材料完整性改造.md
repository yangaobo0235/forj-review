# 报废材料完整性改造（2026-10-16）

影响范围：`contracts` 增量增加上传完整性结果、逐图分类事实和身份证面别提示；`businesses` 在既有 MaterialPolicy 中声明完整性分组；`integrations/recognition` 在字段提取前保留分类事实；`runtime/jobs` 和现有材料评估节点投影结果；扩展的采集、请求协议及 review UI 展示结果。沿用既有 Pack 注册表和主图，不增加节点、能力 ID 或页面权限。

兼容方式：新字段均有空值/空列表默认值，旧请求仍可校验；没有面别提示的身份证只能在内容确认后计入对应面。旧客户端忽略新增结果，新客户端连接旧服务时不展示完整性区。原有 checklist/status 仍表示字段与页码证据质量，新增 presence 专门表示上传状态；不以完整性展示替代人工结论或字段核验。

业务声明：旧车与新车分别要求三类材料；主体资料为营业执照，或身份证正面与反面同时提供。两种方案都传也满足。登记证上传完整性按材料类型检查，原有第 1、2 页质量检查继续保留。无单图标签时先分类，去除报废置换固定序号兜底，分区仍来自页面标题。

不确定性：同分区未分类图片、未知分区图片、采集截断或异常使尚未确认的材料显示待确认；可靠分类不因字段识别失败而丢失。重复同类图不能填补另一类材料，旧车材料不补新车缺项。原图定位沿用当前采集身份保护。

验证范围：两地区规则、乱序与重复、替代方案、单面身份证、分类低置信/失败/超时、分类成功后提取失败、任务合并与渐进状态、DOM 标签及前端折叠展示；运行仓库完整回归和架构检查。

发布：需要同时更新后端和扩展；不需要数据库迁移。回滚时还原本次业务声明、协议和展示提交，重新构建扩展并重启原后端版本。未部署或提交线上审核记录。实际发布 SHA 由发布流程记录。
