# 文档索引

本目录是 FORJ Review Assistant 的长期工程文档，以当前代码为准。历史计划、废弃协议和停用业务不属于现行架构。

当前仓库包含两个独立的 Vue 3 + TypeScript 前端（审核扩展、配置 Web）、两个独立后端（审核服务、配置 Agent），以及共享审核内核与严格的页面 JSON 配置底座。普通页面接入和字段修改优先使用声明式配置，特殊能力通过后端处理器扩展。

## 当前架构的一句话版本

普通页面配置集中在一个页面版本的 JSON 中，编译为共享审核引擎的不可变业务声明；
原生算法和地区政策在 `businesses/packs/`、`businesses/rules/` 扩展。
字段别名、页面分区、材料分组和图片筛选依据由后端采集清单下发给前端。

本地操作见[本地页面配置工作流](指南/本地页面配置工作流.md)；配置底座审查和修复记录见[业务底座与配置 Agent 就绪审查](参考/业务底座与配置Agent就绪审查.md)。

## 文档使用规则

这些文档描述的是当前实现和必须保持的架构约束，不是可以随意忽略的建议。代码、测试和文档出现不一致时，先确认是否发生了已批准的架构变更；如果没有，应修正文档或代码使其重新一致。

每次新增公共类型、节点、注册表、Profile、页面动作或权限时，必须同步更新至少一篇相关文档，并在 PR 中给出链接。发现文档缺失、歧义或与实现不符，应先补充澄清再继续大范围改动。
