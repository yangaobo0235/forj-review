# 文档索引

本目录是 FORJ Review Assistant 的长期工程文档，以当前代码为准。历史计划、废弃协议和停用业务不属于现行架构。

当前仓库包含审核助手前端、审核后端、原生业务声明及严格的页面 JSON 配置底座。普通页面接入和字段修改优先使用声明式配置，特殊能力通过后端处理器扩展。

## 当前架构的一句话版本

一个审核业务的全部配置（字段、材料、材料字段路由、页面地址、能力绑定、地区政策）
集中在 `src/forj_review_assistant/businesses/packs/<业务>.py` 一份声明里，各运行时结构从它生成；
字段别名、页面分区、材料分组和图片筛选依据由后端通过采集清单下发给前端。

## 文档使用规则

这些文档描述的是当前实现和必须保持的架构约束，不是可以随意忽略的建议。代码、测试和文档出现不一致时，先确认是否发生了已批准的架构变更；如果没有，应修正文档或代码使其重新一致。

每次新增公共类型、节点、注册表、Profile、页面动作或权限时，必须同步更新至少一篇相关文档，并在 PR 中给出链接。发现文档缺失、歧义或与实现不符，应先补充澄清再继续大范围改动。
