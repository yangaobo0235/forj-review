# 审核配置使用

## 当前范围

审核配置工作台及配置服务继续在本机运行，用来维护页面的字段、材料、证据映射和已有规则。普通配置不修改 Python、前端源码或任意业务算法。真实业务页的完整操作验收仍需完成，因此目前不部署配置服务到服务器。

启动方式见[本地开发](本地开发.md)。配置服务为 `127.0.0.1:26102`，工作台为 `http://127.0.0.1:26198/`。无需本机登录或扩展配对；模型凭据由后端配置，不填写到前端。

## 从页面开始配置

1. 打开实际审核详情，在扩展“配置页面”点击“采集并打开配置工作台”。页面发现不要求审核服务或已有采集清单。
2. 扩展将页面身份、字段和材料候选保存到本机配置服务，打开带采集 ID 的工作台。完整现场数据不放进 URL。
3. 在“页面范围”选择要审核的字段、供分析的图片和必传材料；查看重复标签、未知控件和数量诊断。
4. 新页面选择“新建页面配置”；修改或回退已有配置时选择对应页面。
5. 开始会话，描述业务要求。例如“增加注册日期核对，读取行驶证注册日期；发动机号不再审核”。助手会查询已支持能力、分析映射并编辑草稿；歧义需要人工澄清。
6. 出现试采集任务时保持原业务标签页和记录，在工作台点击“执行只读试采集”。该操作委托扩展读取页面，不回填或提交审批。
7. 登记独立验收样例，审查字段、材料、规则依据、配置差异、验证和回放结果。
8. 确认无误后点击“确认变更并保存本地版本”。聊天文本“完成”或一轮执行结束不代表已经保存。
9. 待当前审核作业结束后重启使用同一配置空间的审核服务，点击“核对审核服务加载版本”。保存和实际启用是两件事。

只有页面 ID、版本、有效摘要、内核兼容标识及配置来源匹配，才可确认实际加载。页面 JSON 运行时保存在 PostgreSQL 快照中；本地文件修改和工作台保存不会自动更新服务器 `production`。向服务器发布见[部署运维](部署运维.md)。

## 独立验收样例

示例格式见 [permit-cases.json](../examples/page-config/回放样例/permit-cases.json)。样例预期由操作人员提供，助手可以读取和执行，不能通过工具改写预期。已登记 ID 不可覆盖，变更预期应登记新 ID 后重新验证。

在“登记独立验收样例”填写样例 ID 和 `ReplaySuite` JSON，提供候选 `page_id`、`profile_version`、固定 `batch` 和预期。仓库样例只包含虚构值，人工登记的样例默认保存在 `.review-config/case-sets/`，ID 类似 `local/permit-v2`；只读已有样例目录为 `examples/page-config`。

没有代表性独立基准时保留草稿，不能只凭助手说验证成功就保存。固定识别结果回放不能证明真实 DOM 或实际模型识别质量。

## 中断、恢复和回退

- 关闭工作台或重启配置服务后，可从左侧记录继续。会话、采集、事件和检查点保存在 PostgreSQL。
- 模型失败或预算耗尽时草稿保留，排除问题后点击“继续执行”。
- 已确认保存中断后，继续执行会沿用原操作 ID 对账数据库回执；对账完成前不能修改、取消或删除会话。未提交事务自动回滚，重新验证和确认后才能重试。
- 原页面关闭、刷新、切换记录或图片失效后重新采集，在会话“页面范围”选择新现场并更新；旧验证凭据失效，需要重新验证。
- 基础模板被其他会话修改时拒绝覆盖，从最新版本重新建立会话。
- 回退使用已有历史版本，核对、试采和回放后确认，仅切换活动版本，不改写历史内容；随后重启审核服务。
- 可清理未保存会话及其事件和检查点；带正式保存回执的会话保留恢复依据。

需要只读检查 PostgreSQL 存储就绪状态时：

```powershell
uv run forj-review-config-service --check-storage
```

正常运行不依赖本地数据库文件，也不执行建库或迁移。

## 执行约束与排查

配置服务失去数据库持锁连接后，会取消正在执行的任务，健康接口和写操作返回服务不可用。恢复连接后重启配置服务，再从会话继续；新实例接管不会让旧执行器恢复写入权限。发布失败时 PostgreSQL 回滚整个快照事务，已提交的配置与操作回执保持一致，不再需要恢复本地临时文件。

草稿、修订号、选定范围、候选摘要、试采证明及回放报告必须匹配；修改后重新验证。特殊公式、尚未注册的业务算法、复杂条件必传或未知控件会作为能力缺口阻塞，转开发扩展，不能让模型生成任意代码绕过。

模型请求预算由 `CONFIGURATION_MAX_CALLS` 控制，默认 24；另有每轮 120 次工具尝试和 900 秒限制。连续三次相同确定性失败停止重复执行，上下文不足时保留草稿并中断。

日志为 `.review-config/review-config-service.log`，5 MiB 轮转、保留五份归档。排查时使用会话、轮次、工具调用 ID 和错误码；不把完整材料、工具载荷、证件值或模型密钥写入日志。连接、模型变量见各模块 `.env.example`。

## 尚待完成的产品验收

- 在真实 Chrome 审核详情完成采集、范围选择、澄清、试采、独立回放、人工确认和保存。
- 重启后核对实际加载版本，覆盖页面变化、刷新恢复、并发修改及历史回退。
- 在实际控件上验证回填和失败反馈，确认不提交审批、不点击下一步。
- 普通业务人员的可视化验收样例标注器尚未提供，当前仍需登记 JSON。

合成页面、固定识别回放及自动化测试不能代替以上实际业务验收。
