## 4. 组合核对与特殊规则

按稳定编号 R1、R2……写规则，字段表引用编号。每条包含：触发条件、准确输入、比较或推导、正常结果、明确冲突、缺失/不确定/多值、外部失败和人工处理。无对应情况写“不适用”，不能留空暗示已支持。

- 权威链说明优先级，冲突不能多数投票。
- 政策写边界是否包含、超范围是冲突还是待复核。
- 组合字段写清先比什么、如何回填，页面外检查说明有无写回目标。
- 不新增用户未确认的跨材料主体、日期先后或车型推导规则。

## 5. 回填与人工边界

说明可写字段、候选可靠性、控件要求、组合写入、真实选项 ID、回读/恢复、页面切换失效，以及人工可以处理什么。确认字段权限不等于允许跳过唯一定位和原值检查，材料一致也不等于验真或最终审批。
