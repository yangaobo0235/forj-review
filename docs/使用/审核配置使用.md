# 审核配置使用

## 当前范围

工作台和配置服务维护已经由开发接入的页面，一个任务对应一个已有页面的修改。新任务必须先关联已保存的字段与图片来源目录，可以从扩展新采集，也可以在工作台选择历史采集。可新增、删除字段，修改标签、别名、已有区域内定位、材料来源和通用比较方式。手动编辑不调用模型；助手使用相同的草稿和校验。

新页面、特殊算法、新控件和新外部接口由开发接入。已有能力范围内，材料声明、上传要求、专用政策、规则开关、展示及回填映射可通过右侧“专家维护与技术详情”的页面选项维护；材料和字段权限也有受限命令。助手先读取目标活动配置与部署能力，调查依赖、尝试组合及必要澄清；有具体能力缺口才转开发本地接续，不能因一次工具失败直接判定无法完成。当前支持青岛、长春报废置换、车源及过户；一致性保持未配置。

启动见[本地开发](../开发/本地开发.md)。配置服务 `127.0.0.1:26102`，工作台 `http://127.0.0.1:26198/`。无需登录、配对；手动维护无需模型密钥。配置功能仍留本机，真实业务页面验收后再判断部署范围。

顶部“数据库：local · 配置模式”分别表示数据目标与执行能力；网页在 localhost 打开仍是配置服务，不会自动改源码。确需代码时导出接续包，由开发人员显式运行 `forj-review-config-develop`；入口、独立副本、检查与补丁交付见[开发本地代码接续](../开发/审核配置开发.md#开发本地代码接续)。

## 从开始到完成

1. 在业务审核详情页展开相关审核分区并完成材料加载，通过扩展“配置页面”采集并保存字段原值与图片地址；也可直接打开工作台，按页面或地区筛选历史采集。能唯一识别的已有页面自动带入，未识别时人工选择，发布验证仍需核对真实页面身份。
2. 预览采集时间、记录标识、字段值与材料缩略图，确认选对现场。采集提示会注明隐藏材料、未加载和截断范围；局部图片问题允许开始调查，相关证据不足时再补采。确认现场后描述修改要求并开始聊天。
3. 现场只展示控件、图片数量和页面概览，无需逐项勾选。左侧对话表达意图，右侧在“修改结果 / 页面资料 / 处理记录”间切换；发布操作固定在结果底部。任务列表、对话和右侧内容分别滚动，整体页面不滚动。

   “处理记录”顶部固定展示最近动作和状态，运行中的动作显示等待时间；下方按处理轮次展示动作、实际发现、失败原因及下一步。同一次操作的开始与返回合并展示，读取完成不表示配置已经修改。材料观察保留样本编号与模型识别类别，可返回页面资料核对；原始事件编号和错误码放在“排障信息”。结束或中断后，对话区展示本轮结果和已取得的依据。

   阅读位置在底部时自动跟随新增记录；向上查看历史或展开排障信息后暂停跟随，点击“返回最新”恢复。更早记录通过分页加载，加载时保持阅读位置；切换标签后保留位置。遇到问题可复制诊断编号，提供给开发人员关联控制台和文件日志。
4. Agent读取活动配置、部署能力和依赖，按需引用字段或分析材料。引用是调查依据，不等于该字段必须审核或图片必须上传。材料必传属于单独的业务变更，必须在差异中明确呈现。
5. 能查清的问题先调查；确有歧义时列出实际候选，附分区与用途，没有默认答案。可以选择候选，也可用自然语言回答。执行中也可输入更正；系统停止旧执行后按新要求继续，旧验证与确认按需求版本失效。
6. 检查分为配置编译与依赖、真实页面只读采集、独立业务样例、有效需求与业务决定。绑定原标签页的只读试采集会自动尝试一次，失败后保留重试与重新关联现场入口；不回填或提交业务审批。
7. 在右侧核对全部差异、当前要求和检查依据。通过后点击“审阅并发布”，在独立面板再次确认目标页面、环境和版本，再点击“确认发布此版本”。聊天中的“可以”不代替发布操作。
8. 发布后分别核对：发布记录已保存、目标审核服务已加载、指定业务浏览器使用本次配置完成只读采集。三项齐备才显示本次任务完成；页面刷新或关闭时重新关联现场再核对。

工作台固定使用白色与淡蓝色的亮色主题，不随系统深色设置切换。新建任务时，桌面左侧准备页面资料、右侧描述修改要求，两侧内容独立滚动，开始操作固定在右侧底部；窄屏按资料、要求顺序排列，在工作区内滚动。

任务内桌面保持左对话、右结果，两栏等宽；窄屏通过“对话 / 结果 / 资料 / 记录”切换。资料引用先放入输入区，补充说明后一起发送，不会立即触发修改。Enter换行，Ctrl/Cmd+Enter发送，中文输入法组字期间不会误发。已输入但未发送的会话文本保存在本机，发送失败保留文本；未知网络结果重试原消息或发布身份。

配置保存到 PostgreSQL `forj_review.local` 的页面、字段、材料和发布关系表。线上继续使用 `public`，两者不自动同步。核对只覆盖实际检查的服务与指定浏览器；已经启动的审核任务继续使用原快照。实际加载失败时展示原因，可重试核对或准备历史版本恢复。

采集是某一时刻的字段原值和图片来源目录，不是永久冻结的原图库。数据库只保存HTTP(S)地址、原始标签、分区、分组和定位线索，不下载或存储图片二进制。浏览器按需加载预览，模型分析时直接接收所需图片地址。浏览器能打开不表示云端模型能访问；链接过期或需要登录时重新采集相关材料。`blob:`/`data:`无原始HTTP来源时标记不支持，不偷偷转存原图。

选择历史采集创建新任务时使用当前活动配置；继续旧任务保留原页面基线。单条记录缺材料不表示该页面不要求材料。切换采集保留目标、草稿和旧目录，通过标签、分区与定位比较对应关系；不按候选序号复用，不把旧图片识别结果继承到新来源。
历史证据可用于调查、草稿和固定样例回放，发布前仍须关联当前页面完成只读验证。试采集证明有效期为15分钟。页面、候选或相应绑定变化后重新检查，不接受任意 `ok=true` 代替原始采集事实。发布后的新现场只用于采用核对，不改写原发布的验证报告。

## 手动维护

右侧“专家维护与技术详情”与Agent共用同一候选。新增字段填写稳定标识、名称、别名、已有分区、材料字段与来源；新字段默认不能回填。删除字段会清理它独占的路由和无消费者提取项，保留共享输入；规则、身份、动作或处理器依赖会显示阻止原因。

仅页面输入的普通字段若显示“可设置材料比较”，可在编辑中选择已有比较方式及材料来源，不需要新写专项规则。能否修改由后端的真实依赖校验决定；有身份、专用规则或其他实现依赖的字段不会因手动编辑绕过保护。材料读取指引与标准字段来源可以调整，不能借此将购买方、销售方或不同分区的事实混为一项。

无专用依赖的普通系统输入也可以从审核配置删除，删除后不再生成该字段的核对或缺失确认任务，也不提供回填目标；业务页面上的原输入框保持原样。后续需要核对时，重新采集页面并通过新增字段配置接入明确的材料来源。

人工修改后，旧检查及确认失效，重新执行现场映射、只读试采集、独立回放与完整验证，再在同一发布面板确认。参考字段允许最终被删除，不要求每个引用都映射到最终审核项；材料必传按明确业务目标维护，不从引用推断。手动维护不调用模型，不能跳过同一套内核校验。

## 使用助手

在同一会话描述字段要求，例如“新增发动机号核对，读取行驶证发动机号”。助手可查询配置、分析材料、记录映射、修改普通字段、请求试采集和运行回放。遇到歧义先回答澄清问题，受保护依赖和新能力转开发处理。

线上配置助手不能创建页面或改变稳定身份，不提供代码、Shell 或 SQL 执行工具。已有页面选项和受限材料、权限操作仍须通过依赖检查、试采集、回放和人工确认；未知参数明确拒绝。对话说“完成”不是保存；始终审查真实验证结果并由操作人员确认。手动和助手不能同时覆盖不同修订号的草稿。

### 更正、查询与三条处理路径

用户可以用自然语言更正或撤回先前要求，也可以询问状态；右侧只列出当前有效要求。补充回答继续作为本轮需求资料，局部更正只替换对应目标及依赖它的判断，保留独立目标；旧验证和发布确认需要重新核对。名称、日期或来源的属性预期会与真实候选检查；RESOLVED只代表处理意见，审核语义还要独立样例回放。当前已满足的要求可以给出无需修改结论，不发布空版本。待处理问题支持候选和自由文本，取消交互后可重新描述。

- 配置路径：已有能力可表达时，形成同一个候选，经过独立样例、试采集、验证、明确确认发布、服务加载及指定浏览器采用核对。
- 本地代码路径：需要新算法、控件或接口时，展示调查依据并导出开发接续包，由开发人员本地运行代码 Agent，产出补丁与报告。在“开发人员：导入本地接续报告”选择本地 report.json，核对包摘要、需求版本、改动文件与检查范围。导入只记录开发人员提供的报告，不应用补丁或证明部署；代码未部署前，相应新配置不能发布。
- 人工接续：本地调查后仍无法可靠实现或验收，报告列明实际证据、障碍及人工决策项。缺现场、业务口径待澄清、环境故障和预算中断分别等待或恢复，不直接算过于复杂。

混合要求默认整体等待。仅当部分目标可独立验收，才在“更新基线与独立拆分”选择该部分、说明独立性并明确同意，形成关联子任务；原任务保留全部目标，子任务从当前活动配置重新调查、修改和验证。

本地入口及受控运行见[审核配置开发](../开发/审核配置开发.md)。线上工具成功与本地检查通过都不代表业务审核通过。

## 独立验收样例

在“业务验收预期”选择对应业务已登记的样例集，可直接“使用已有独立预期回放”，不必重复冻结。源文件、固定输入和预期保持不变，执行时仅将目标页面版本重绑定到当前候选。

缺少或改变业务口径时，“读取输入与预期”展示固定页面值、材料事实和整单/字段/规则预期。人工核对并调整预期，勾选明确确认后登记新ID；切换任务、样例或目标版本会清空尚未冻结的内容。新增复杂材料事实仍由开发人员准备 ReplaySuite，格式见[合成回放样例](../../examples/page-config/回放样例/permit-cases.json)。可精确核对比较字段、任务字段、清单字段及允许写回字段。

回放不会连接模型服务、二维码网站或数据库。涉及发动机排放查表时，在对应 case 中提供 `engine_emissions`，例如 `{"Q23-132E60": "国六"}`；空对象表示固定的未命中结果，未提供则按参考数据不可用处理，需要人工复核。材料已明确记载排放标准时无需此项。

样例预期由操作人员维护，助手不能改写评分依据。已登记 ID 不能覆盖，变更时登记新 ID。人工登记文件默认在 `.review-config/case-sets/`，ID 例如 `local/permit-v2`。固定回放不读取真实图片、不调用模型或官网，不能替代 DOM 与识别质量验收。

## 恢复和回退

- 关闭页面或重启配置服务后从会话记录继续，草稿与事件保存在 PostgreSQL。界面读取近期消息，完整消息可通过分页接口获取。
- 可以归档未发布任务，需求、草稿与已保存证据仍保留；恢复后可以继续调查，发布前重新验证。闲置 30 天的未发布任务自动归档，归档后继续保留 30 天，之后按保留策略清理。已确认待对账的操作不自动归档。
- 模型中断不影响手动编辑。已确认但保存中断时先“继续执行”对账，期间冻结编辑、取消和删除。
- 模型预算耗尽表示本轮处理已中断，不表示已生成修改或通过验证。查看右侧真实差异；尚无差异时不要把“可以恢复”当成修改成功。处理记录区分查阅配置、更新草稿与处理中断，恢复仍须完成业务澄清和后续验证。
- 模型服务返回限流时明确提示限流并停止本轮，保留已有调查记录和草稿；稍后再继续，不自动反复请求消耗预算。
- 相同调查复用结果，接近预算时优先编辑、澄清或说明具体限制。重复确定性失败或无法收口会明确暂停，已有依据和草稿保留；这不表示需求过于复杂，也不自动转为本地代码任务。
- 原业务标签页刷新、切换记录或关闭后，已保存证据仍可调查；需要实时验证时重新采集并更新会话现场。更换现场后，旧证据在“页面资料”的采集选择中只读查看，不覆盖新现场或恢复旧证明。
- 同一目标页面的正式配置变化时，使用“比较并更新基线”，查看原基线、本候选及当前活动值；无冲突自动合并，有冲突逐项选择保留哪一侧，没有默认答案。确认后创建关联接续任务，保留目标与非冲突修改，重新取证验证；原任务与历史不变。其他页面发布不会单独使本任务失效；提交时按最新发布清单组合并原子核对，保留他人的修改。
- 在“页面版本记录与恢复”选择历史版本，先预览恢复差异；重新试采集、独立回放和明确确认后产生新发布，再做采用核对，原发布历史不变。
- 已发布的会话可以清理，正式发布和验证仍长期保留。已确认但尚未落库的操作必须先对账，不能当成普通草稿直接删除。

CLI、完整迁移和程序恢复见[审核配置开发](../开发/审核配置开发.md)。导出候选与试采集证明可供 CLI 使用，文件包含现场数据，应按业务数据保管。

未关联任务的历史采集保留7天；任务引用过的目录随任务保留，更换现场或归档不会提前清理旧目录。删除任务后，过期且无其他任务引用的目录按保留策略清理。正式页面版本、发布和发布引用验证独立保留，聊天清理不改变正常审核使用的活动配置。

## 尚需真实环境验收

自动化检查覆盖合成页面、固定证据、并发、回滚及保存恢复。实际业务仍须验证 Chrome 页面采集、控件定位、试采集、自动加载和允许的回填行为。已提供基于现有样例的可视预期核对与冻结；原始材料事实与新增样例输入仍由人工准备。配置服务未作为服务器进程部署。
