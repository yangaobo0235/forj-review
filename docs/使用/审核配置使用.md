# 审核配置使用

## 当前范围

工作台和配置服务在本机运行，维护已经由开发接入的页面普通字段。可新增、删除字段，修改标签、别名、已有区域内定位、材料来源和通用比较方式。手动编辑不调用模型；助手使用相同的草稿和校验。

新页面、特殊算法、新控件和新外部接口由开发接入。已有能力范围内，材料声明、上传要求、专用政策、规则开关、展示及回填映射可通过右侧“页面选项”维护；材料和字段权限也有受限命令。界面显示依赖或不支持能力时转开发处理。当前支持青岛、长春报废置换、车源及过户；一致性保持未配置。

启动见[本地开发](../开发/本地开发.md)。配置服务 `127.0.0.1:26102`，工作台 `http://127.0.0.1:26198/`。无需登录、配对；手动维护无需模型密钥。配置功能仍留本机，真实业务页面验收后再判断部署范围。

## 手动维护

1. 打开真实审核详情，在扩展“配置页面”点击“采集并打开配置工作台”。
2. 选择已接入页面，选择需要核对的现场字段和材料。没有新建页面选项。
3. 新建修改会话，进入右侧“手动字段”。新增字段填写稳定标识、名称、别名、已有分区、材料字段与来源；编辑时不更换稳定键。新增字段默认不能回填。
4. 删除字段会清理它拥有的路由和不再使用的提取项。共享输入保留；规则、身份、动作或处理器依赖会显示原因并阻止删除。
5. 在“现场映射与独立验证”确认现场字段、图片与配置对象的映射；如之前使用过助手，人工核对相关要求后勾选已处理项。
6. 创建并执行只读试采集，保持原业务标签页、记录和现场。该操作不回填、不提交审批。
7. 登记并选择人工确认预期的独立样例集，执行回放，再验证当前候选。
8. 在“变更与验证”审查新增、删除、修改的字段及阻塞原因。通过后点击确认保存。
9. 等待自动加载，点击“核对审核服务加载版本”。新配置编译失败时保留旧快照，已有作业仍用原版本。刷新业务页面并重新采集。

配置保存到 PostgreSQL `forj_review.local` 的页面、字段、材料和发布关系表。线上继续使用 `public`；本地变更不会自动同步到线上。保存成功表示“已发布”，随后独立检查实际加载；发布批次、页面、版本、有效摘要、内核兼容标识与来源均匹配才显示实际已加载。

试采集证明有 15 分钟有效期，页面、范围或草稿变化后重新采集与回放。不得导入任意 ok=true 代替原始事实。

## 使用助手

在同一会话描述字段要求，例如“新增发动机号核对，读取行驶证发动机号”。助手可查询配置、分析材料、记录映射、修改普通字段、请求试采集和运行回放。遇到歧义先回答澄清问题，受保护依赖和新能力转开发处理。

助手不能创建页面或改变稳定身份，不能编写算法、控件或新接口。已有页面选项和受限材料、权限操作仍须通过依赖检查、试采集、回放和人工确认；未知参数明确拒绝。对话说“完成”不是保存；始终审查真实验证结果并由操作人员确认。手动和助手不能同时覆盖不同修订号的草稿。

## 独立验收样例

在“配置草稿与验收工具”登记 ReplaySuite JSON。格式见[合成回放样例](../../examples/page-config/回放样例/permit-cases.json)。request.page_id 与 profile_version 必须指向当前候选，提供固定 batch 与预期；可精确核对比较字段、任务字段、清单字段及允许写回字段。

回放不会连接模型服务、二维码网站或数据库。涉及发动机排放查表时，在对应 case 中提供 `engine_emissions`，例如 `{"Q23-132E60": "国六"}`；空对象表示固定的未命中结果，未提供则按参考数据不可用处理，需要人工复核。材料已明确记载排放标准时无需此项。

样例预期由操作人员维护，助手不能改写评分依据。已登记 ID 不能覆盖，变更时登记新 ID。人工登记文件默认在 `.review-config/case-sets/`，ID 例如 `local/permit-v2`。固定回放不读取真实图片、不调用模型或官网，不能替代 DOM 与识别质量验收。

## 恢复和回退

- 关闭页面或重启配置服务后从会话记录继续，草稿与事件保存在 PostgreSQL。
- 模型中断不影响手动编辑。已确认但保存中断时先“继续执行”对账，期间冻结编辑、取消和删除。
- 原业务标签页刷新、切换记录或关闭后重新采集，再更新会话现场。
- 基础配置被他人改变后，从最新版本创建会话；不会静默覆盖。
- 回退时选择已有页面和历史版本，试采集、独立回放、验证后确认，仅切换活动版本，等待自动加载。
- 已发布的会话可以清理，正式发布和验证仍长期保留。已确认但尚未落库的操作必须先对账，不能当成普通草稿直接删除。

CLI、完整迁移和程序恢复见[审核配置开发](../开发/审核配置开发.md)。导出候选与试采集证明可供 CLI 使用，文件包含现场数据，应按业务数据保管。

## 尚需真实环境验收

自动化检查覆盖合成页面、固定证据、并发、回滚及保存恢复。实际业务仍须验证 Chrome 页面采集、控件定位、试采集、自动加载和允许的回填行为。可视化样例标注器尚未提供，样例仍以 JSON 登记。配置服务未作为服务器进程部署。
