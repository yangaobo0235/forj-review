# 审核浏览器扩展

审核辅助的前端：读取业务页面、展示证据与审核任务，并执行受控页面操作。

`npm run dev` / `npm run preview` 使用 `127.0.0.1:26199`；本机审核 API 为 `127.0.0.1:26101`，服务器审核 API 为 `175.178.6.214:26101`。实际浏览器扩展需构建后加载，自身不监听前端端口。
